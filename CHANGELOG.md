# Changelog

As mudanças relevantes deste projeto são registradas neste arquivo. O formato segue o
[Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e os commits seguem
[Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/).

## [Unreleased]

### Added

- Governança do repositório com GitHub Actions, CODEOWNERS, templates de issues e PR,
  Dependabot, políticas de contribuição, suporte, segurança e conduta.
- Hooks do Husky e validação de commits com Commitlint.
- Validação de sintaxe dos módulos JavaScript do app estático.
- App estático em três shells, site institucional, painel administrativo e documentos técnicos.
- Faturamento recorrente, gateways de pagamento, Pix recorrente e bloqueio por pendência.
- Ecossistema de IA com RAG, OCR, integrações de LLMs e versículos diários.

### Changed

- README raiz passa a apresentar as duas implementações e o fluxo de desenvolvimento.
- Raiz do GitHub Pages redireciona para o app estático publicado.
