# Suporte

Antes de abrir uma issue:

1. Consulte o [README](README.md) e o [README do app estático](pastorhub-static/README.md).
2. Leia o [Manual do usuário](pastorhub-static/docs/manual-usuario.html).
3. Consulte o [Registro Técnico](pastorhub-static/docs/registro-tecnico.html), especialmente as
   limitações conhecidas.
4. Pesquise as issues existentes para evitar duplicações.

## Canais

- **Bug:** use [ISSUE_TEMPLATE/bug_report.yml](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Nova funcionalidade:** use [ISSUE_TEMPLATE/feature_request.yml](.github/ISSUE_TEMPLATE/feature_request.yml).
- **Contribuição:** siga o [CONTRIBUTING.md](CONTRIBUTING.md).
- **Vulnerabilidade:** não abra issue; siga o [SECURITY.md](SECURITY.md).

O projeto é mantido por voluntários. Não há SLA de atendimento; incluir reprodução clara,
ambiente, capturas e logs aumenta a chance de uma resolução rápida.
